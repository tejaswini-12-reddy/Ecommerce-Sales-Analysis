Ecommerce Sales Analysis

Project Overview

This project analyzes ecommerce sales data using Python to understand sales patterns and generate useful business insights.

Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib

Project Files

- "Ecommerce_Sales_Analysis.ipynb" – Jupyter Notebook containing Python code, analysis and visualizations.
- "amazon_ecommerce_1M" – Ecommerce dataset.

Dataset

The dataset is available here:
[Download Ecommerce Dataset](https://drive.google.com/file/d/1dWaHP648aHX27fSalSJDZzcGDRpUOi1A/view?usp=sharing)


Project Features

- Data analysis using Pandas and NumPy
- Data visualization using Matplotlib
- Sales data exploration
- Graphical representation of analysis results

How to Run

1. Download the dataset.
2. Open the Jupyter Notebook.
3. Install the required Python libraries.
4. Run the notebook cells to view the analysis.
